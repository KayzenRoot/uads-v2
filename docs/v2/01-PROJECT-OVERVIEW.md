# UADS V2 — Project Overview

Status: CANONICAL OVERLAY IN REVIEW

## Mission

UADS V2 evolves UADS V1 into a more predictable, cost-aware and adaptive software execution runtime while preserving the proven V1 foundation.

The V2 target is not an agent swarm. It is a bounded engineering runtime that selects the smallest safe amount of context, model capability, reasoning effort, specialist work and verification necessary to reach a trusted result.

## Product outcomes

- lower token/quota waste;
- fewer duplicated analyses;
- sequential specialist execution by default;
- one user-visible primary session when host capabilities permit;
- automatic host/model/reasoning-effort selection;
- safer and faster bug resolution;
- evidence-first review compatible with Hive V2 HEDS;
- measurable Time-to-Trusted-Merge;
- controlled operational learning without autonomous mutation of canonical truth.

## Relationship to V1

V2 starts from the exact V1 code and governance baseline. V1 continues to exist and can remain installed/used independently while V2 is developed.

## Relationship to Hive V2

Hive V2 is the macro/canonical layer. UADS V2 is the bounded execution/micro-orchestration layer. Their integration must exchange identity, context, proof obligations and evidence without duplicating canonical memory, governance or review policy.
