# ADR-UADS2-001 — V1 Lineage

Status: ACCEPTED  
Date: 2026-09-09

## Decision
UADS V2 starts from the exact tracked tree of `KayzenRoot/uads@312e32946798eb3abbb49a79af08e13efb7719dc`. UADS V1 remains untouched and independently usable.

## Rationale
Preserve working capability, avoid rewrite risk, enable objective V1×V2 regression measurement and retain provenance.

## Consequence
Bootstrap must prove source equivalence before V2 behavior changes.
