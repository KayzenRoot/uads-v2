# ADR-UADS2-005 — Hive V2 / UADS V2 Boundary

Status: ACCEPTED  
Date: 2026-09-09

## Decision
Hive V2 owns macro/canonical truth, durable organizational/project memory, governance and HEDS policy. UADS V2 owns bounded software execution and micro-orchestration.

UADS emits HEDS-compatible evidence rather than building a competing canonical review/governance system.

## Consequence
Integration uses explicit task/evidence contracts. No silent cross-system promotion of truth.
