# M03 S01.5 — Technology Invention Radar

Status: FROZEN CANDIDATE — WO-005 HEDS PENDING

No invention is accepted merely because it is novel. Each must beat a simpler baseline under S04.

## M03-P01 — Proof-Carrying Capability Record (PCCR)

### Problem
Snapshot-wide provenance cannot explain which evidence proves one feature or whether that proof is still current.

### Candidate
Each capability record carries:
- capabilityId;
- state;
- evidenceClass;
- subjectDigest;
- probeId + probeDefinitionDigest;
- observedAt;
- validUntil or validity rule;
- evidenceDigest;
- policyDigest;
- reasonCodes;
- proofDigest.

### Baseline
Current tri-state capability + global snapshot provenance.

### Expected advantage
Zero ambiguous per-feature provenance and deterministic stale/tamper rejection.

### Falsifier
Reject PCCR if it cannot achieve 100% covered-drift invalidation with acceptable storage/probe overhead or if a simpler per-feature timestamp+source model provides equivalent safety.

### Fallback
Legacy tri-state remains compatibility projection; no unsafe enablement.

## M03-P02 — Capability Evidence Ladder (CEL)

Evidence rungs:
- E0 NONE;
- E1 DECLARED;
- E2 DETERMINISTIC_LOCAL_FACT;
- E3 SAFE_ACTIVE_PROBE;
- E4 APPROVAL_GATED_PROBE.

A capability policy defines minimum evidence rung for `SUPPORTED`.

### Safety rule
E1 declaration alone MUST NOT enable high-impact worker/model/effort controls.

### Falsifier
Reject CEL if fixed per-capability proof rules are simpler and equally auditable without duplicated logic.

## M03-P03 — Negative Proof Contract (NPC)

### Problem
Absence is not proof of non-support.

### UNSUPPORTED may be emitted only when at least one condition is satisfied
1. authoritative complete feature enumeration for the exact subject/version explicitly excludes the capability;
2. deterministic active probe returns a version-bound recognized unsupported result;
3. a fixed adapter contract itself defines a capability impossible by construction and the contract digest is bound to proof.

Missing file, missing host, timeout, permission denial, parse error or unrecognized output yields UNKNOWN/BLOCKED, never UNSUPPORTED.

### Falsifier
Any adversarial case where transient absence becomes false/UNSUPPORTED fails the invention.

## M03-P04 — Capability Lease & Drift Sentinel (CLDS)

A proof is reusable only while its validity basis matches:
- subject identity digest;
- adapter contract digest;
- probe definition digest;
- relevant configuration digest where privacy-safe;
- policy digest;
- evidence artifact digest;
- expiry/freshness rule.

Any mismatch => STALE before projection.

### Falsifier
Any covered drift mutation that leaves proof enabled fails CLDS.

## M03-P05 — Probe Budget Fence (PBF)

Automatic probes are restricted to predefined descriptors.

Descriptor includes:
- executable identity rule;
- fixed argument template;
- side-effect class;
- network policy;
- timeout;
- max output bytes;
- environment allowlist;
- parser version;
- supported platforms.

Automatic policy:
- READ_ONLY_LOCAL: may run automatically;
- TEMPORARY_LOCAL: only in isolated temp root and only when explicitly designated safe;
- NETWORK or MUTATING: blocked in initial M03; future explicit approval/ADR required.

### Falsifier
Any descriptor that allows arbitrary shell interpolation, inherited secret exposure or unbounded execution fails the candidate.

## Promotion recommendation

Promote PCCR, CEL, NPC, CLDS and PBF as **architectural targets** for S05.
Only host-specific active probe implementations remain EXPERIMENT until their dedicated benchmark cases pass.
