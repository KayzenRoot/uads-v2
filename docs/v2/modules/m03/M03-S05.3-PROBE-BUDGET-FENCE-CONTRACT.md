# M03 S05.3 — Probe Budget Fence Runtime Contract

Status: FROZEN BEFORE IMPLEMENTATION
Work Order: UADS2-WO-008
Issue: #32

## Boundary

The generic executor answers only:
**"Did this fixed safe registered probe execute under its declared safety envelope, and what privacy-safe receipt resulted?"**

It does NOT answer:
**"Is this host capability supported?"**

That semantic mapping belongs to a later vendor-specific experiment + PCCR compiler gate.

## Descriptor registry

Production callers pass `probeId`, never descriptor objects.

Registry lookup returns a compiled fixed descriptor.

A public descriptor compiler may exist for validation/testing, but execution accepts only registered IDs.

TEST_ONLY fixtures are accessible only when `NODE_ENV === "test"`.

## Executable rule

Initial enum contains one value:
`node-current`.

Resolution is direct `process.execPath`. No PATH lookup or arbitrary absolute path parameter.

## Environment

Hard safe environment names:
- SystemRoot
- WINDIR
- TEMP
- TMP
- TMPDIR
- HOME
- USERPROFILE
- LANG
- LC_ALL

Descriptor may request a subset only.

No PATH required.

## Output

Raw child output is process-memory-only.

Receipt stores SHA-256 digests, byte counts and a bounded parser summary.

## Parser set

Initial:
- `node-version-v1`
- `exit-code-v1`

No vendor text parser.

## Test hooks

To deterministically test identity drift, a test-only identity provider hook may be accepted only when `NODE_ENV === "test"`.

It cannot alter executable/args/env and cannot exist in durable receipt.

## Persistence

Probe receipts are additive diagnostic artifacts under global runtime capability registry.

Receipt persistence cannot create or modify PCCR proof files.

## Failure semantics

BLOCKED is returned before spawn for policy/platform/test-only violations.

TIMED_OUT / OUTPUT_LIMIT / FAILED / IDENTITY_DRIFT are non-success receipt states and cannot become capability truth.

Only SUCCEEDED means the generic probe ran successfully. It still does not imply capability support.
