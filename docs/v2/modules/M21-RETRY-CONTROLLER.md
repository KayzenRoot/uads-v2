# M21 — Retry Controller
Status: DISCOVERY | Class: NECESSARY

Mission: prevent blind retry loops and allow another attempt only when hypothesis, evidence, parameters or justified capability escalation changes.

Standalone: internal controller. Hive complement: optional program budget can tighten retry ceiling.

Candidate technology radar, UNAPPROVED: retry novelty digest; retry budget token; exponential evidence backoff; loop-cycle detector.

Sessions S00–S07 cover retry taxonomy, control algorithm, state architecture, runaway/failure model, adversarial tests, slices, cost integration, freeze.

Mandatory tests: identical retry rejected, bounded attempts, changed hypothesis accepted, escalation receipt, terminal failure preserved.
