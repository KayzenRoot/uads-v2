# M29 — Operational Security & Supply Chain
Status: DISCOVERY | Class: NECESSARY

Mission: make security a production operating property.

Owns threat modeling, least privilege/RBAC boundaries, secret lifecycle, environment isolation, secure defaults, dependency/supply-chain controls, SBOM where appropriate, SAST/DAST/security gates, audit-log requirements and incident-response readiness.

Composes with M03, M08, M15/M16, M18, M19 and M25.

Mandatory evidence: privilege tests, secret leakage prevention, supply-chain policy, SBOM where applicable, security-gate evidence, audit integrity and incident-response/runbook exercise.
